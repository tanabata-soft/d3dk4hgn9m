# ニコラスケイジと木曽と私 ― デジタルCDアルバム

コンピレーションアルバム『ニコラスケイジと木曽と私』(全10曲+ボーナストラック1曲、総再生時間 約32分)を聴くための PWA(デジタルCDアルバム、NK-001)。

公開 URL: https://tanabata-soft.github.io/nicholas-kiso-album/

## 使い方

- **表ジャケット**: タップ/横スワイプで裏面(曲名リスト)に反転する。下のボタンは 曲目 / 再生(全曲) / ブックレット。
- **曲目**: 曲をタップすると、その曲から再生する。
- **再生画面**: 歌詞が曲に合わせて流れる(自分でスクロールもでき、手を離して3秒で再生位置に戻る)。ジャケットをタップすると盤面(円盤)モード。前/次は端でループし、「前」は3秒より進んでいたら曲の先頭に戻る。バックグラウンド再生(Media Session)と画面スリープ防止に対応。
- **ブックレット**: 全14ページ(ライナーノーツ2 + 曲ページ11 + 奥付)。ページの左右スワイプ/ドラッグでめくる。末尾にインストール方法とバージョン表示がある。
- ホーム画面に追加するとアプリとして使え、オフラインでも開ける(音源は再生した曲から順にキャッシュされる)。

## 構成

エンジン(仕組み)とデータ(作品)を分けている。新しいアルバムは、データの差し替えだけで作れる(手順は [docs/PRODUCTION.md](./docs/PRODUCTION.md))。

- `src/album/`: **このアルバムのデータ一式(差し替え対象)**
  - `album.ts`: 題名・カタログ番号・ライナーノーツ・奥付の文面
  - `tracks.ts`: 曲目・解説(正本)
  - `sync.ts`: 歌詞の同期データ(各 mp4 の字幕から生成した生成物)
  - `media.ts`: 曲ごとの画像・音源の対応
  - `assets/`: 画像と音源(mp4)。`jacket.jpg` / `back.jpg` / `bg.jpg` と `trackNN.jpg` / `trackNN.mp4` の固定スロット
- `src/logic.ts`: 純関数のロジック(時刻整形、曲順の循環、歌詞の現在行、ブックレット構成)
- `src/main.ts`: 画面と再生の制御

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm run verify       # lint → test → build → check:dist → check:content
npx playwright install chromium && npm run test:e2e
npm run shots        # 主な画面の一括撮影(shots/all.png)
npm run build:preview # 作業確認用の単一 HTML(dist-preview/preview.html。音源は 96kbps 化して埋め込む)
```

ルールの詳細は [CLAUDE.md](./CLAUDE.md)、作業の状態は [docs/HANDOVER.md](./docs/HANDOVER.md) を参照。

## デバッグモード

ブックレット末尾のバージョン表示(`デジタルCDアルバム v1.0.0`)を続けて 5 回タップすると、左下に操作パネル(DEBUG)が出る。画面移動のショートカット用。もう一度 5 回タップするか、パネルの「終了」で消える。
